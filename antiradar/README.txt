Антирадар РБ (отдельное приложение, модуль antiradar)

Предупреждает о камерах фиксации скорости по базе координат: «Впереди камера на 60 через 300 метров».
Озвучка на 1000 / 500 / 300 м (русский голос Android TTS, если он установлен), баннер поверх навигатора.

Как пользоваться:
1. Откройте приложение, нажмите «База камер…»: загрузите файл с камерами (CSV или speedcam.txt, скачанный вами из российской базы, например RadarInfo.ru: PocketGPS CSV или Navitel) через «Загрузить из файла» или «по ссылке», либо возьмите камеры из OpenStreetMap. Из файла берутся только камеры Башкортостана.
2. Нажмите СТАРТ и разрешите геолокацию. Для баннера поверх навигатора нажмите «Поверх окон».
3. Если заметили камеру, которой нет в базе, нажмите «+ Камера здесь», когда проезжаете её.

База OpenStreetMap может быть неполной и не учитывает мобильные посты. Данные © участники OpenStreetMap, ODbL.
Приложение не обнаруживает радиосигнал радаров, оно только предупреждает по известным координатам.
