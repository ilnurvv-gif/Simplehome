SIMPLE HOME - простой быстрый лаунчер для магнитолы

СБОРКА (Android Studio):
1. File -> Open -> выберите папку SimpleHome. Дождитесь Gradle Sync.
2. Build -> Build Bundle(s) / APK(s) -> Build APK(s).
3. APK: app/build/outputs/apk/debug/app-debug.apk

УСТАНОВКА:
1. Скопируйте APK на флешку или установите через adb: adb install app-debug.apk
2. Нажмите кнопку Home на магнитоле, выберите "Simple Home" -> "Всегда".
   Вернуть родной лаунчер: Настройки -> Приложения -> Приложения по умолчанию -> Главное приложение.

ВАЖНО: родной лаунчер магнитолы НЕ удаляйте и не отключайте, пока не проверите,
что радио, камера заднего вида и руль работают через ваш лаунчер.

Управление: короткое нажатие - запуск, долгое - "О приложении" (отключить/остановить).
Фон статичный, без анимаций и виджетов - поэтому не тормозит.
